# cmd-util: Command line utilities

Clone the repository:
```
cd <CMD_UTIL_PARENT_DIRECTORY>
git clone https://github.com/michaelgrieco/cmd-util.git
cd cmd-util
```

Build the C-tools:
```
cd src
make all
```

Add the following line to your `.bashrc`:
```
source <CMD_UTIL_PARENT_DIRECTORY>/cmd-util/env.sh
```
